# escuela-plataforma
Plataforma minimalista en Flask para la Escuela de Misterios de la Sabiduría. Gestión de 22 niveles, autenticación por roles (aprendiz, ejecutor, maestro, admin). Desplegable en Render. Código para una orden de aprendizaje cooperativo.
